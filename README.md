# Aspirra

AI-powered personal operating system that turns goals into practical plans, actions, opportunities, and measurable progress.

## Product principle

Goal → Plan → Action → Evidence → Progress → Adjustment

Aspirra is not intended to be a generic chatbot. AI will be an intelligence layer inside a structured personal progress system.

## Foundation milestone

- Mobile-first responsive React/Vite application
- PWA manifest and installable-app foundation
- Persistent local state for goals and actions
- Goal creation flow
- Starter planning engine
- Daily action view
- Action completion and progress calculation
- Goals, Progress, and AI Guide navigation
- Modular planner/AI boundary ready for a real model provider
- No secrets or API keys stored in the client

## Development

Run npm install, then npm run dev.

Build with npm run build.

Tests with npm test.

## Roadmap

1. Foundation and product shell
2. Persistent account/data layer
3. Real AI orchestration and model-provider adapter
4. Goal decomposition and adaptive planning
5. Evidence and progress intelligence
6. I'm stuck guidance
7. Career, money, learning, and opportunity modules
8. Notifications and reminders
9. Production security, QA, analytics, and deployment
10. Android packaging and release preparation

Aspirra should grow through completed vertical slices rather than disconnected screens.
